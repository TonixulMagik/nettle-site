Add Nettle to your server

  1. Open the invite

    Press Add Nettle to Discord and pick your server. You need the Manage Server permission there.

    Add Nettle to Discord (opens in a new tab)

  2. Check what Nettle asks for

    Discord shows a list of permissions. Keep them all ticked. If you take some away, parts of Nettle will not work.

    Nettle asks for 19 permissions and never for Administrator. It does not ask for Mention @everyone, so it can only ping roles that are set as mentionable.

    See all 19 permissions
    • View Channels
    • Send Messages
    • Send Messages in Threads
    • Embed Links
    • Attach Files
    • Read Message History
    • Use External Emojis
    • Manage Messages
    • Pin Messages
    • Manage Threads
    • Manage Channels
    • Manage Roles
    • Kick Members
    • Ban Members
    • Timeout Members
    • Create Expressions
    • Connect
    • Move Members
    • Set Voice Channel Status

  3. Move Nettle's role

    Go to Server Settings, then Roles. Drag the Nettle role above the roles it should give out or manage. Keep it below your team and admin roles. Discord only lets a bot handle roles that sit below its own.

    Example order, from top to bottom

    1. Admin
    2. Team
    3. Nettle
    4. Roles Nettle gives out
    5. @everyone

  4. Set the basics

    Type /setari to open Nettle's settings for your server.

On your own account

You can also add Nettle to your own Discord account instead of a server. Added to your account, Nettle has one command for now, /about, which works in DMs, group DMs and on any server. Every other command is a server command and needs Nettle to be added to the server.

Basic setup

Each server has its own settings. A change on one server does not touch another.

Nettle only works in channels it can see. If a channel has its own permissions, let Nettle see it and send messages there.

Common problems

I can't see Nettle's commands

Type / in a channel and look for Nettle. If it is not there, add Nettle again with the button on this site. Check that your role can use app commands in that channel. Then restart Discord. New commands can take a moment to show up.

Nettle also opens in steps. Before 1 November 2026 at 8 PM Romania time, only a few commands show up.

Nettle can't give or remove a role

Move Nettle's role above that role, like in step 3. Discord does not let a bot change a role that is higher than its own, or at the same level.

Nettle doesn't answer in one channel

That channel probably has its own permissions. Let Nettle see the channel, send messages and embed links there.

A button says the interaction failed

This can happen just after Nettle restarts, or on a very old message. Try the command again. If it keeps happening, tell us on the support server.

Nettle answers in Romanian

Nettle itself speaks Romanian. Every command, button and message the bot sends is in Romanian. That is normal for now.

Report a bug

The fastest way is the support server. Tell us what you did, what you expected, what happened instead, and about when. A screenshot helps. Please don't post private things from your server.

Your data

You can ask what Nettle knows about you. You can ask for a copy, a fix, or to have it deleted. Write to supportnettle@gmail.com or open a ticket on the support server. Add your Discord user ID.

Part 8 of the Privacy Policy explains what is kept and how requests work.

How to find your user ID. In Discord, open User Settings, then Advanced, and turn on Developer Mode. Then right-click your name and pick Copy User ID.
